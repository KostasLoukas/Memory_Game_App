# Memory Game - A Windows Forms Application

This Windows Forms Application is a game that tests one's memory. The goal of this game is to lift all pairs of images that exist
in the game's table consecutively.

The game starts with a simple button as shown below:
<img width="620" height="307" alt="image" src="https://github.com/user-attachments/assets/6d4fea79-e8ed-4e76-8fb2-a1ec1d34b379" />

When the button is clicked, the table below appears:
<img width="619" height="324" alt="image" src="https://github.com/user-attachments/assets/d158e767-4508-46c4-9f84-aee0cde60087" />

Then, the user has to turn two blocks of the table by clicking on them and if they are a pair they will stay visible, whereas if 
they are unmatched, the blocks will go back to being hidden after a short amount of time.
<img width="616" height="340" alt="image" src="https://github.com/user-attachments/assets/8cbb80db-77f7-4483-a86b-dc6f15194a30" />

When the player has finally managed to turn all the pairs of blocks correctly, then the following message will be displayed and
the game will end:
